## [2.5.0.RELEASE] - 2026-06-02
### Changed
- Upgrade frontend to Angular 20 and PrimeNG 20 (replace deprecated/removed components, mostly p-dropdown)
- Update Spring Boot to 3.5.14 and Tomcat to 10.1.54
- Update dependencies to fix vulnerabilities
- Update button styling in the EVS theme
### Fixed
- Report tasks and report template handle the table reference more reliably
- Report template table is more forgiving of the global filter
